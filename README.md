# CineSnap 🎬📸

*A prototype mixing Instagram and Letterboxd.*

*Share your screen. Connect through cinema.*

**CineSnap** is a modern Flutter application designed for cinephiles to connect, share their cinematic moments, and discover new movies. Built with a stunning dark theme and a premium glassmorphic UI, CineSnap provides a seamless and visually engaging experience.

## ✨ Features
- **Modern User Interface**: Premium dark mode aesthetics with glassmorphic elements and staggered grid layouts.
- **Secure Authentication**: Integration with both Firebase Auth and Supabase for secure user authentication, including Google Sign-In.
- **Real-time Database**: Cloud Firestore handles fast, real-time data syncing.
- **Media Storage**: Firebase Storage integration for media sharing.
- **Dynamic State Management**: Efficient state management powered by Provider.

## 🛠 Tech Stack
- **Framework**: Flutter (Dart)
- **Backend & Auth**: Firebase (Core, Auth, Firestore, Storage), Supabase
- **UI/UX Components**: `cupertino_icons`, `shimmer`, `flutter_staggered_grid_view`, Google Fonts
- **State Management**: `provider`

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (v3.10.3 or higher)
- Dart SDK
- Android Studio / Xcode for emulators
